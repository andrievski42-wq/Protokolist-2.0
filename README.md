# Протоколист 4.0 — офисный CPU

Версия рассчитана на обычный офисный компьютер без дискретной видеокарты.

## Рекомендуемые настройки

- живая модель: `turbo`;
- финальная модель: `medium`;
- вычисления: `CPU / int8`;
- окно живой расшифровки: `15 секунд`;
- улучшение аудио: включено;
- коррекция по корпоративному словарю: включена.

## Корпоративный словарь

Файл:

```text
data/corporate_terms.json
```

Раздел `terms` содержит правильные фамилии, модели изделий, аббревиатуры и
технические термины. Раздел `replacements` содержит известные ошибочные варианты.

После редактирования сохраните JSON и перезапустите приложение.

## Почему не large-v3

На обычном офисном процессоре `large-v3` может работать значительно медленнее
реального времени и занимать много памяти. Сочетание `turbo` для чернового текста
и `medium` для итоговой расшифровки практичнее.

## Запуск

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

FFmpeg должен быть установлен и доступен в PATH.

## Ограничение

Корпоративная коррекция не заменяет полноценную языковую модель. Итоговую
стенограмму и автоматически выделенные поручения необходимо проверять человеком.
