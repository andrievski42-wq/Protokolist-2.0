# Контекст проекта «Протоколист»

## Назначение

«Протоколист» — офлайн-приложение для записи производственных совещаний,
распознавания русской речи, подготовки протоколов, выделения решений и поручений,
а также поиска по архиву совещаний.

## Условия эксплуатации

- Windows.
- Обычный офисный компьютер без дискретной видеокарты.
- Распознавание должно работать полностью офлайн.
- Основной язык — русский.
- Типичные совещания длятся от 30 минут до 2 часов.
- В речи часто встречаются производственные и технические термины.
- Возможны несколько говорящих, шум и большое расстояние до микрофона.

## Текущий технологический стек

- Python 3.12.
- CustomTkinter — интерфейс.
- sounddevice и soundfile — запись звука.
- Faster-Whisper — распознавание речи.
- FFmpeg — подготовка аудио.
- python-docx — экспорт Word.
- openpyxl — экспорт поручений в Excel.
- Git и GitHub — контроль версий.

## Выбор моделей распознавания

Для офисного компьютера используется двухэтапная схема:

- `turbo` — живая черновая расшифровка;
- `medium` — итоговая расшифровка после окончания совещания.

`large-v3` не используется по умолчанию из-за высокой нагрузки на CPU и память.

## Корпоративный словарь

Файл `data/corporate_terms.json` содержит:

- правильные названия изделий;
- фамилии сотрудников;
- сокращения;
- технические термины;
- известные ошибочные варианты распознавания.

## Главные требования

1. Не терять аудио и текст при сбоях.
2. Не отправлять записи во внешние сервисы.
3. Сохранять каждое совещание отдельным проектом.
4. Позволять редактировать стенограмму и протокол.
5. Выделять решения и поручения.
6. Позволять искать информацию по архиву.
7. Работать на обычном офисном ПК.
