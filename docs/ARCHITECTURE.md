# Архитектура

## Текущие модули

```text
main.py
gui/
audio/
whisper_engine/
analysis_engine/
storage/
export/
data/
archive/
recordings/
```

## Ответственность модулей

### `gui`
Интерфейс, кнопки, вкладки, статусы и взаимодействие пользователя с приложением.

### `audio`
Выбор микрофона, запись звука, подготовка аудио и управление временными фрагментами.

### `whisper_engine`
Загрузка модели Faster-Whisper и преобразование аудио в текст.

### `analysis_engine`
Коррекция по корпоративному словарю, выделение решений и поручений,
формирование черновика протокола.

### `storage`
Создание, сохранение, загрузка и поиск проектов совещаний.

### `export`
Экспорт протоколов и поручений в Word и Excel.

## Целевая архитектура версии 5.0

```text
src/protokolist/
├── app/
├── audio/
├── asr/
├── analysis/
├── domain/
├── storage/
├── export/
└── ui/
```

Переход к структуре `src/` следует выполнять постепенно, без одновременного
перемещения всех файлов, чтобы не сломать рабочую версию.

## Принципы

- Интерфейс не должен выполнять тяжёлые операции в главном потоке.
- Запись и распознавание должны быть разделены.
- Модель распознавания должна заменяться без изменений в интерфейсе.
- Работа с файлами должна быть сосредоточена в `storage`.
- Данные совещания должны передаваться через объект модели.
- Любая новая функция должна сопровождаться тестом.
